Music Course Builder — General Help

Use Subjects to organize broad areas of practice, Topics for lessons or repertoire, and folders to organize material inside each Topic.

Getting started

Choose File → New to create a project, or File → Open to open an existing project. Open a Subject, then a Topic to work with its media.

Projects and saving

Use File → Save or Save as to save project JSON. Make a copy creates a separate project. Export Bundle packages a project with supported local media; Import Bundle restores it. Keep backup copies of important work.

Adding and organizing media

Use Add Files, Add YouTube, or drag and drop to add material. You can create folders, rename items, and relink missing local files when opening projects on a different device.

Practice Room and players

Open an audio, video, YouTube, or PDF item to access its player. Available controls vary by media type; audio playback may include speed, waveform navigation, and loop markers. PDF viewing includes additional layout tools.

Utilities

Choose Utilities → Metronome or Utilities → Recorder. The recorder can capture a selected audio input or a shared tab when supported by your browser. Browser permissions are required for recording.

Browser and file troubleshooting

If local media is missing, use Relink to choose its file again. Browser storage and file access differ by device; Chrome and Safari may behave differently. Recording and file permissions are controlled by the browser.
